## Blocking defects

### QA-S2-001 — High: missing required strings cause unhandled HTTP 500

Reproduction:

```http
POST /api/v1/orders
Content-Type: application/json

{"productSku":"SKU-QA","quantity":1}
```

The same behavior occurs with `"customerReference": null`, omitted `productSku`, or `"productSku": null`. Expected: HTTP 400 with a validation Problem Details response. Actual: HTTP 500 with no content type and an empty body. Log Analytics independently recorded Kestrel event 13, “An unhandled exception was thrown by the application,” on the tested revision at the reproduction times. The process recovered and remained healthy, but untrusted client input must not generate server failures.
